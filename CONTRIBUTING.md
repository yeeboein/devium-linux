# Helping with Devium

Thanks for wanting to help! Join the [Devium Discord](https://discord.gg/YTMattgyG3) to chat first.

## Ways to help
- **Test** betas on your computer and file a hardware report or bug (Issues > New issue).
- **Translate** Devium's apps: see `docs/translations` (one file per language).
- **Icons and artwork:** the icon theme is generated by `tools/make-icons.py` and `tools/make-folder-icons.py`.
- **Code:** apps and helpers live in `profile/airootfs/usr/lib/devium` and `profile/airootfs/usr/local/bin`.

## Code rules
- Keep the 4 GB laptop in mind: nothing that runs all the time unless it has to.
- Everything optional is off by default (Customise tweaks, extras).
- No emojis in Devium apps; use theme icons.
- Files that only exist on the live USB must not end up on installed systems.
- An update copies new files but doesn't delete old ones: add clean-up for removed files in
  `package_setup` (`usr/lib/devium/devium-setup`).
- Run `tools/check-code.sh` before pushing; pull requests run the same checks (`.github/workflows/checks.yml`).

## Building an ISO
On an Arch machine: `sudo EDITION=kdeplasma ./build.sh` (or `xfce`, `hyprland`). Or run the "Build Devium ISO"
workflow on GitHub.
