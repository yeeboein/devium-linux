## 2. Light. Fast. Yours.

Most distros either give you everything or nothing. Devium gives you a clean, fast desktop, then asks what
you actually want. You get exactly that, and nothing else.

- **Light:** runs on 2 GB of RAM and fits in 10 GB of disk.
- **Fast:** Arch underneath, so your apps are always up to date.
- **Yours:** pick your browser, editor, languages and look. Change your mind any time.

## 3. Devium Configure

**Image:** `images/devium-configure.png` (also `images/devium-configure-languages.png`)

### Pick only what you want.

After installing, Devium Configure walks you through your browser, file manager, terminal, code editor,
programming languages, Python libraries, developer tools, games and apps. Every choice shows how much space
it takes, so you always know what you're getting.

Changed your mind? Open it again. Everything you have is already ticked. Untick something and it's removed.

---

## 4. Devium Tools

**Image:** `images/devium-tools.png` (also `images/devium-tools-windows.png`)

### Your whole PC, in one place.

- **App Manager:** see every app's size and how much memory it uses, and remove it in one click.
- **Safe updates:** a restore point first, and an undo button if anything goes wrong.
- **Make it faster:** safe speed tweaks, plus Low-RAM mode for older laptops.
- **Battery:** health, and a charge limit to make your battery last longer.
- **Privacy:** firewall, Wi-Fi tracking and location, all in plain switches.
- **Coming from Windows?** It shows you where everything is, and copies your files over.

Open it with **Meta+T**.

## 5. Built for coding

**Image:** `images/terminal-fastfetch.png`

### Code from the first minute.

VS Code or VSCodium, Python, C/C++, Rust, Go, Java, Node.js and more are one click away in Devium Configure.
Git and GitHub set up step by step. Docker or Podman when you need them. An optional AI that runs on your own

And when something breaks, type `support fix` and Devium checks and repairs the usual suspects.

## 10. FAQ

**Is Devium free?**
Yes. Free to download, free to use, and open source.

**Is it based on Arch?**
Yes. Devium uses Arch Linux's own packages, so you get the latest software and the Arch Wiki still applies.

**Will it run on my old laptop?**
Very likely. Devium runs on 2 GB of RAM. On 4 GB or less it turns on Low-RAM mode by itself, and the Xfce
edition is lighter still.

**Can I install it next to Windows?**
Yes. The installer can shrink a partition and set up a boot menu so you can pick Devium or Windows when your
computer starts.

**Is it stable?**
Devium is in beta. It's great for trying out and for spare laptops; expect the odd bug, and tell us on
Discord when you find one.

**Does Devium collect my data?**
No. Devium collects nothing. A problem report is only sent when you press Send, and you see exactly what's
in it.

**How is it different from other Arch distros?**
It's built around coding and ease: Devium Configure picks your apps with sizes shown, Devium Tools looks after
your PC, and updates come with an undo button.
