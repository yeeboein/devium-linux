# Devium beta8.5

Same as [beta8](https://github.com/yeeboein/devium-linux/releases/tag/beta8), but the **KDE Plasma ISO is one file again**:
no more joining `.000` and `.001` parts, and it's smaller (about 1.9 GB). Download it, put it in VirtualBox (or on a USB stick), done.

To make it smaller, the ISO only carries translations for English, Irish, Spanish, French, German,
Portuguese, Italian, Dutch, Polish and Russian. Other languages come back with your first update.

## What's in beta8 (and this release)
- **Devium Tools** (Meta+T): App Manager, Safe Updates with undo, Make it faster, Low-RAM mode, battery,
  privacy, printers, Docker/Podman, Git and GitHub connect, Coming from Windows, accessibility,
  languages (Irish, Spanish, French, German) and Report a problem
- **Devium Setup**: open it any time to add or remove things, optional **Local AI**, **Magnify dock**,
  more Python sets, Helium browser, theme previews
- **Installer**: Encrypt system option, Join the Devium Discord (QR code)
- **Terminal**: `support fix`, `support <word>`, `devium-ram`
