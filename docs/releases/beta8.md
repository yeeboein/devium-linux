# Devium beta8

The biggest update yet: a new **Devium Tools** app, an easier **Devium Setup** you can come back to any time,
optional local AI, disk encryption, Irish and other languages, and lots of fixes.

## New: Devium Tools (Meta+T)
- **Devium Hub**: one place for every Devium app, plus disk and memory at a glance
- **App Manager**: see every app's size and average RAM, and remove it
- **Safe Updates**: Arch news before you update, **Undo last update**, optional automatic updates
- **Make it faster** button and **Low-RAM mode** (turns on by itself on 4 GB computers)
- **Battery** health and charge limit
- **Privacy** dashboard: firewall, random Wi-Fi address, location, recent files
- **Printers and scanners** in one click
- **Docker / Podman** and a step-by-step **Git and GitHub** connect
- **Coming from Windows**: where things are, same shortcuts, copy your files from a Windows drive
- **Accessibility**: larger text, screen reader, zoom, sticky keys, fewer animations
- **Languages**: Irish (Gaeilge), Spanish, French, German
- **Get help**: fix common problems, Support commands, **Report a problem** straight to the Devium team

## Devium Setup
- Open it any time: installed things start ticked, untick to remove them
- **Local AI** (optional): Ollama + Alpaca, only models that fit your RAM are shown
- **Magnify dock** option ([linux-magnify](https://github.com/yeeboein/linux-magnify))
- More Python sets: maths, images, games, GUIs, command-line tools, databases, scraping, documents
- Helium browser, Quickshell checkbox, theme previews, "Apps" is now "Packages"
- Cancel button, and "Not enough space" takes you back to the start
- ArchPill installs Quickshell by itself and starts right after setup

## Installer
- **Encrypt system** option (password-protected disk)
- No more "Disks & Devices" pop-up while installing
- Join the Devium Discord from the slideshow (QR code)

## Terminal
- `support fix` repairs common problems, `support <word>` searches, `devium-ram` shows memory use
- fastfetch only runs when you type `fastfetch`

## Fixed
- "unable to lock database" after an interrupted install
- Light mode text was too faint
- Long descriptions in Devium Setup were cut off
